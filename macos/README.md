Native 3.0 preview. Requires macOS 14+ and Apple Silicon. Run swift build in this directory or use the GitHub Actions macOS workflow. Initial model download requires internet. Import web JSON backups through Sermon library. TXT and Markdown exports only in this preview. Ad-hoc signed, not notarized. Existing web app remains separate.

## Local build
On an Apple Silicon Mac, install Xcode or command line tools (`xcode-select --install`). Clone the repository, then run `bash macos/build-local.sh` from its root. The script compiles, packages, ad-hoc signs and creates `macos/dist/Sermon-Studio-macOS-arm64.dmg`. Build output is saved to `macos/dist/build.log`. To rebuild, run `git pull --ff-only` then rerun the script. No automatic installation or archive changes are performed.

## Sparkle updates
The updater is disabled unless a trusted Ed25519 public key is supplied at build time. Obtain Sparkle's official release tools from https://github.com/sparkle-project/Sparkle/releases and run its generate_keys tool on your Mac. Keep the private key in your Keychain; never commit or share it. Build with SERMON_UPDATE_PUBLIC_KEY set to the generated public key. Future releases must increment CFBundleVersion, package the app, sign the update archive using Sparkle sign_update or generate_appcast, publish the archive and publish the signed appcast.xml at the configured GitHub Pages URL. Test update installation before distributing. Ad-hoc signing is not notarization. Automatic installation is disabled; finish transcription and save edits before approving an update. The existing cloud workflow does not yet package Sparkle or publish signed updates; use the local script for this preview.
